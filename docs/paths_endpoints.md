
# Файл путей и эндпойнтов

## Пути
| Путь | Что показывает |
| --- | --- |
| ```/``` | Основная страница с чатом (ПУСТАЯ! ЧАТ НЕ ОТКРЫТ!) |
| ```/:chat_id``` | Основная страница, чат с chat_id открыт |
| ```/:chat_id/:msg_id/:document_id``` | Split-view документа и конрктного сообщения |


## Эндпойнты 
| Эндпойнт | Что делает | Что в ```body``` | На какой странице | Ожидаемый ответ | Что должен сделать сервер |
| --- | --- | --- | --- | --- | --- |
| ```POST /api/v1/new_chat``` | Создает новый чат | Первые N символов первого сообщения в чате (эти же N символов и будут названием чата) | ```/``` | chat_id созданного чата | Создать новый чат с указанным названием и присвоить ему chat_id |
| ```GET /api/v1/chats``` | Получает список чатов и их названия (пока ТОЛЬКО это) | *нет* | ```/``` | Массив объектов (словарей) вида {id_чата: название_чата} | Выдать список чатов в указанном формате |
| ```GET /api/v1/:chat_id/history``` | Получает все сообщения из чата с указанным chat_id | *нет* | ```/``` | Данные о сообщениях пользователя, ответах llm (включая цветовое выделение нужных мест и у сообщений пользователя, и у ответов llm), использованные документы для каждого ответа llm (название и id документа), идентификаторы сообщений пользователя и ответов llm в хронологическом порядке | Выдать сообщения в чате в указанном формате |
| ```POST /api/v1/:chat_id/user_message``` | Отправляет новое сообщение пользователя | Текст сообщения | ```/:chat_id``` | Ответ llm на это сообщение (включая цветовое выделение), использваонные документы | Получить сообщение пользователя, передать его в llm, вернуть на клиент ответ от llm |
| ```GET /api/v1/:chat_id/:msg_id/:document_id``` | Получает сообщение и документы | *нет* | ```/:chat_id/:msg_id/:document_id``` | Сообщение пользователя с указанным id, ответ llm с указанным id (включая цветовое выделение нужных мест и у сообщения пользователя, и у ответа llm), использованные документы для каждого ответа llm (название и id документа), сам открытый документ (название и id документа) (ВАЖНО! нужны все документы + выбраный, не только что-то одно!) | Выдать сообщение и документы |
